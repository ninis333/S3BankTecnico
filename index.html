Solução Financeira Digital • Web & Mobile

Transformando o hábito de guardar dinheiro em evolução real

O S3Bank é uma solução financeira digital criada para apoiar jovens e estudantes na organização das finanças pessoais, no acompanhamento transparente de movimentações e na construção da constância financeira. Por meio de caixinhas com metas, fluxo Pix demonstrativo e gamificação por pontos de constância, o usuário evolui de nível e desbloqueia rendimentos maiores do CDI.

Foco na Constância

Aportes concedem pontos fixos + fração do valor, recompensando a frequência do hábito, não apenas altos valores.

Ecossistema Duplo

Site institucional/demonstrativo em React + Vite e aplicativo funcional multiplataforma em Flutter + Dart.

Segurança em Nuvem

Integração Mobile com Supabase Auth, PostgreSQL, funções transacionais RPC e políticas RLS por linha.

Arquitetura & Stack Tecnológica

O S3Bank não segue um padrão MVC monolítico tradicional: a camada Web adota componentização declarativa em React, enquanto o aplicativo Mobile implementa separação por responsabilidades (Screens, Models, Providers, Services, Widgets e Core).

Camada Web

React 18 + Vite

  • • Interface modular por componentes
  • • Navegação SPA com React Router
  • • Tokens visuais em CSS customizado
Camada Mobile

Flutter / Dart

  • • Material 3 (Dark Theme)
  • • Estado reativo via Provider
  • • Gerador BR Code Pix (EMV + CRC16)
Backend & Auth

Supabase

  • • Supabase Auth (Cadastro, Login, Reset)
  • • Funções RPC transacionais
  • • Trigger handle_new_user
Persistência

PostgreSQL

  • • 8 tabelas relacionais estruturadas
  • • Row Level Security (RLS) por linha
  • • Validação de saldo no servidor

Estrutura Lógica de Dados (PostgreSQL / Supabase)

Relação das 8 tabelas identificadas no repositório Mobile e suas responsabilidades conceituais.

Tabela Responsabilidade Conceitual Operações / Segurança
perfis Informações associadas ao perfil do usuário e pontos de constância. Criado via trigger handle_new_user • RLS
carteiras Dados da carteira principal e informações de saldo disponível. Bônus inicial R$ 1.000 • Atualizado via RPC
transacoes Registros do histórico de movimentações financeiras (extrato). Funções enviar_pix / receber_pix
caixinhas Metas ou reservas de economia criadas pelo usuário. RPC depositar_caixinha / resgatar_caixinha
cartoes Informações do cartão digital vinculado ao nível do usuário. Sincronizado via CardProvider.syncTier
chaves_pix Chaves Pix demonstrativas vinculadas ao usuário (CPF, e-mail, celular, aleatória). Inserção e exclusão protegidas por RLS
regras_nivel Parâmetros de pontuação e progressão (Bronze, Prata, Ouro, Diamante). Consulta de faixas de pontos
taxas_cdi Percentuais demonstrativos de rendimento associados ao CDI por nível. 100% a 140% do CDI (parâmetro ilustrativo)
